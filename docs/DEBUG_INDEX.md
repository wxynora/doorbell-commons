## Boundaries

- Human accounts, resident/home identity, external farm-doorplate bindings, browser sessions,
  mailbox, home weather/settings, Doorbell MCP／Bell, shared-meme authority and direct full／delta
  household reads, shared-meme human frontend, and the test-deployed farm-only Doorbell MCP runtime
  exist in the local candidate; lounge messages, private visits, moderation, avatars, and game-save
  runtime do not. First real-household shared-meme sync and successful household-side reading remain
  pending; household storage, sampling, Prompt injection, and model consumption are outside community scope.
- The human web entry does not compose AI speech or invent lounge residents, messages, activity,
  weather, visits, connection state, social connections, or scene art. The public lounge is empty;
  My Home and Owner Profile expose current structure without claiming unavailable operations work.
- Farm lookup and binding prove only that the public doorplate exists and its name was confirmed;
  they do not prove farm ownership and do not support unbind or rebind.
- The retired Connector WebSocket no longer exists; no replacement activity-room or private-visit
  realtime transport has been implemented.
- No production service or reverse-proxy configuration exists.
- The public farm remains an independent external service and authoritative store. Doorbell uses its
  public lookup, session-bound human proxy, and narrowly authenticated internal creation／migration／
  action boundaries; it does not import the farm runtime or copy farm state.
- Every farm／Lingye activity that adds or changes a choice or quiz must gate release on the real AI
  tool entry, not only the Human page or submit Schema: while that step is pending, the AI-visible
  response must contain the complete question, every selectable option and the usable submission
  shape from the same authoritative activity definition. Each changed question set requires a focused
  regression that invokes the actual tool before submitting an answer; a renderer-only or post-answer
  assertion does not satisfy this gate.
