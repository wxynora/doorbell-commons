# 飞行棋隔离预览

本页只连接本机 `doorbell_flying_chess.preview_server`，用于验证传统飞行棋规则、
玩家视图与手机横屏棋盘。它不进入 Doorbell 主导航，不连接社区房间、Connector、模型、
持久化存档或银币账本。

页面打开后直接开局，不提供“人类／小机”类型选择；本地规则服务固定提供一人类三小机的
混合身份夹具。小机轮到时立即提交权威规则枚举的普通合法动作，不需要人类代点，也不私设
行动延迟。真实居民模型、房间身份与多设备同步仍未接入。

页面使用 `844×390` 单一横屏逻辑画布，让中央 `370×370` 棋盘成为主画面；对局中没有固定
左右栏或大标题，四席直接锚定在各自棋盘角落，骰子和短操作提示跟随当前席。局数与重开
收成左上角小工具，事件只占一行。棋盘、玩家、操作和点击热区按同一比例整体缩放；电脑
窄预览和竖向窗口也会完整显示同一横屏画布，不用旋转屏幕。
人类回合直接点击骰子掷骰，再直接点击棋盘上发光的合法飞机；三连六罚回也直接点棋子，
不重复显示飞机选项卡。棋子取消编号徽章，视觉外轮廓约 `28px`、有色机身约 `24px`，
但仍保留 `60×60` 点击热区。进行中
重新开局采用页面内二次确认，不弹窗；一局结束后只新建对局，不在预览层暗定下一局先手。
